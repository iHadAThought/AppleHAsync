Shared sources

Enable a calendar or reminder list, then choose which details sync to Home Assistant for that source.

Calendars

Always syncs title, start, and end. Optional: notes, location, URL.

Reminder lists

Always syncs title and completion. Optional: notes, due, priority, flag, location, URL, tags.

Focus Mode

Mac → Home Assistant only (read). Requires Full Disk Access for appleHAsync so the agent can read the Focus database. Cross-device Focus may lag or miss local Assertions.
